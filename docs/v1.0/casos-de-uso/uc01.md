# UC01 — Listar Tarefas

![RF01](https://img.shields.io/badge/RF-01-blueviolet?style=flat-square)
![Pré-condição](https://img.shields.io/badge/pré--condição-logado-green?style=flat-square)

| | |
|---|---|
| **Descrição** | O usuário pode visualizar as tarefas de um dia. |
| **Pré-condições** | Estar logado no sistema. |

---

## :arrow_forward: Fluxo Principal

1. O sistema direciona o usuário para a **tela inicial**;
2. A tela inicial exibe:
  - Filtro de **data** *(padrão: Hoje)*
  - Filtro de **tag** *(padrão: Todos)*
  - Filtro de **status** *(padrão: Pendentes)*
  - Lista de tarefas de acordo com os filtros aplicados
  - Botão **`+`** para criar nova tarefa
3. Este caso de uso pode acionar **[UC02](uc02.md)** ou **[UC03](uc03.md)** dependendo da interação do usuário.

---

## :twisted_rightwards_arrows: Diagrama de Sequência

```mermaid
sequenceDiagram
  autonumber
  actor U as Usuário
  participant UI as Tela Inicial
  participant F as TaskFacade
  participant R as TaskRuleRepository
  participant G as OccurrenceGenerator
  participant S as OccurrenceStatusResolver

  U->>UI: Abre o aplicativo
  UI->>F: loadTasks()
  F->>R: getAll(userId)
  R-->>F: TaskRule[] (roots + exceptions)

  Note over F,G: Gera ocorrências para o período visível (ex: hoje)

  F->>G: generate(rules, exceptions, from, to)
  G-->>F: Occurrence[] (virtuais, em memória)

  loop Para cada Occurrence
    F->>S: resolve(occurrence, historyRecord?)
    S-->>F: TaskStatus (PENDING, COMPLETED, FAILED, SKIPPED)
  end

  F-->>UI: Occurrence[] com status resolvido
  UI-->>U: Exibe lista filtrada por data, tag e status

  Note over UI: Filtros padrão: Hoje / Todos / Pendentes
```
