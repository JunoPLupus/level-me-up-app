## :notepad_spiral: Sobre o projeto

O **Level Me Up** nasceu como uma *Task List* simples desenvolvida para a disciplina de *Projeto de Interface Web* no curso de Sistemas para Internet do IFTO (Campus Palmas), e evoluiu para um aplicativo com foco em arquitetura escalável e mecânicas de gamificação.

Ao concluir uma tarefa, o usuário ganha XP que é distribuído entre seu perfil geral e as habilidades vinculadas — criando um sistema de progressão contínua.

---

## :dart: V1.0 — MVP (Core Loop)

O foco da versão 1.0 é implementar o ciclo central da gamificação:

| | Funcionalidade | Descrição |
|---|---|---|
| :calendar: | **Tarefas** | Criar, visualizar, editar (regras e exceções), excluir e concluir |
| :chart_with_upwards_trend: | **Gamificação básica** | Ganho de XP, barra de progresso e sistema de níveis |
| :muscle: | **Habilidades** | Vincular tarefas a habilidades específicas (ex: "Programação") |
| :triangular_flag_on_post: | **Tags** | Organização das tarefas por etiquetas coloridas |
| :bust_in_silhouette: | **Perfil** | Login com Google e visualização de estatísticas básicas |
